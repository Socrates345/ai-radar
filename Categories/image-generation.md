# Image Generation

> Personal selection of the best image generation models and tools at their respective release dates. Sorted newest first.

### Image Generation
#### [Qwen-Image-2.1](https://github.com/QwenLM/Qwen-Image-2.1) — `09.2026` — `open-source` `local` `free`
Alibaba's 7B open-weight unified image generation/editing model — native transparency (RGBA), up to 10-reference-image editing, 2K output; runs locally on consumer hardware. Research license only, not for commercial use.
#### [ChatGPT Images 2.5 / GPT-Image-2.5](https://openai.com/index/introducing-chatgpt-images-2-5/) — `09.2026` — `online` `api` `paid`
OpenAI's updated image engine — sharper detail, more reliable multi-turn editing, up to 50% faster generation than Images 2.0; API ships as GPT-Image-2.5 Flare (speed) and Sunburst (quality). *(supersedes ChatGPT Images 2.0 / GPT-Image-2)*
#### [Reve 2.1](https://reve.art/) — `07.2026` — `online`
Reve's "image as code" layout-first model — reasons about layout/hierarchy before rendering, native 4K, strong in-image text rendering; ranked #2 on Text-to-Image Arena behind GPT-Image-2. *(supersedes reve.art/2.0)*
#### [Muse Image](https://ai.meta.com/blog/introducing-muse-image-muse-video-msl/) — `07.2026` — `online` `free`
Meta Superintelligence Labs' first image generation/editing model, agentic by default — web search for factual grounding, code execution for charts/QR codes, self-correction of drafts.
#### [Qwen Image 3](https://qwen.ai/blog?id=qwen-image-3.0) — `07.2026` — `api` `online` `paid`
Alibaba Qwen's third-generation image model accepting up to 4,500-token prompts for single-pass generation of complex layouts, dense infographics, and legible small text across 12 languages.
#### [Seedream 5.0](https://seed.bytedance.com/en/blog/beyond-generation-it-understands-design-introducing-seedream-5-0-pro) — `07.2026` — `online` `paid`
ByteDance's design-focused image model — complex infographics/information visualization, precision region-editing, photoreal output, native multi-language on-image text. *(supersedes Seedream 4.0)*
#### [Ideogram 4.0](https://github.com/ideogram-oss/ideogram4) — `06.2026` — `open-source` `local` `free`
Ideogram's first open-weight model (9.3B-param DiT); ranked #1 open-weight and #2 overall (behind GPT-Image-2) in independent quality evaluations. *(supersedes Ideogram)*
#### [Microsoft MAI-Image-2.5](https://microsoft.ai/news/introducing-mai-image-2-5/) — `06.2026` — `online` `paid`
Microsoft Superintelligence team's image generation/editing model; #3 on Arena's text-to-image leaderboard and #2 on image-editing, with strong facial-identity preservation across edits.
#### [PixelDiT](https://huggingface.co/Comfy-Org/PixelDiT/tree/main) — `06.2026` — `open-source` `local` `free`
Pixel-space diffusion model for high-resolution (4K) image generation/upscaling, distributed as ComfyUI checkpoints.
#### [Krea 2](https://www.krea.ai/krea-2-open-source) — `05.2026` — `open-source` `local` `free`
Krea's first foundation image model built from scratch (12.9B-param DiT); ships as Krea 2 Raw (undistilled, for fine-tuning) and Krea 2 Turbo (8-step distilled, ~2s for 2K images).
#### [Z-Image](https://github.com/Tongyi-MAI/Z-Image) — `04.2026` — `open-source` `local` `free`
Alibaba/Tongyi-MAI's open-source image generation initiative; best local model at 02.2026 release. Includes Z-Image-Turbo and Z-Image-Edit variants.
#### [FLUX.2 Klein](https://github.com/black-forest-labs/flux2) — `02.2026` — `open-source` `local` `free`
Black Forest Labs' 4B-parameter rectified flow transformer built for sub-second image generation and native image editing; designed for local use (13GB VRAM).
#### [Nano Banana 2](https://blog.google/innovation-and-ai/technology/ai/nano-banana-2/) — `02.2026` — `online` `api` `freemium`
Google's state-of-the-art image generation/editing model (Gemini 3.1 Flash Image) — Pro-level visual quality at Flash speed, web-grounded knowledge, precise text rendering, up to 4K output.
#### [Qwen Image 2](https://arxiv.org/abs/2605.10730) — `01.2026` — `open-source`
Alibaba's omni-capable foundation model unifying high-fidelity text-to-image generation and precise image editing.
#### [Ovis Image](https://github.com/AIDC-AI/Ovis-Image) — `12.2025` — `open-source` `local` `free`
Specialized in calligraphy and text-rich image generation.
#### [PosterCopilot](https://postercopilot.github.io) — `12.2025`
AI-driven poster and layout generation.
#### [Pomelli](https://labs.google/pomelli/about/) — `12.2025` — `online` `free`
Google's brand and design system generator — full visual identity from a prompt.
#### [NanoBanana Pro](https://blog.google/innovation-and-ai/technology/ai/nano-banana-2/) — `11.2025` — `online` `api` `freemium`
Google's Gemini-3-Pro-based image generation/editing model — cinematic quality and strong graphic-design output; predecessor to Nano Banana 2.
#### [Lumina-DiMOO](https://synbol.github.io/Lumina-DiMOO/) — `10.2025` — `open-source` `research`
Versatile image generation model with strong general-purpose performance.
#### [Qwen-Image](https://huggingface.co/spaces/Qwen/Qwen-Image) — `08.2025` — `open-source` `online` `free`
Qwen's multimodal image generation model; best-in-class as of August 2025.
#### [OmniGen 2](https://vectorspacelab.github.io/OmniGen2/) — `06.2025` — `open-source` `research`
Unified multimodal generator following complex fine-grained instructions, with decoupled architecture and built-in self-correction.
#### [Imagen 4](https://deepmind.google/technologies/imagen/) — `05.2025` — `online` `paid`
Google DeepMind's image generation model; top-tier at release.
#### [Higgsfield Soul](https://higgsfield.ai/) — `04.2025` — `online`
Specialized in generating realistic human portraits and faces.
#### [FLUX 1.1 Pro Ultra](https://replicate.com/black-forest-labs/flux-1.1-pro-ultra) — `11.2024` — `api` `paid`
Black Forest Labs' highest-quality FLUX API variant.
#### [FLUX.1 KREA dev](https://krea.ai/) — `11.2024` — `online` `free`
High-quality FLUX fine-tune available for free through KREA AI.
#### [Recraft v3](https://replicate.com/recraft-ai/recraft-v3) — `11.2024` — `online` `paid`
Top-performing image generation model in benchmarks; especially strong for design and vector work.
#### [Leonardo.ai](https://app.leonardo.ai/) — `online` `freemium` `platform`
Full-featured image generation platform supporting FLUX and other leading models.
