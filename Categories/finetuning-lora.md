# Fine-Tuning & LoRA

> Tools, frameworks, and resources for fine-tuning, LoRA training, and model customization.

---

## Fine-Tuning Frameworks

### [Unsloth](https://docs.unsloth.ai/get-started/fine-tuning-guide)

Fastest fine-tuning framework for LLMs; supports LoRA, GGUF export, and runs on as little as 7GB RAM. Go-to for local fine-tuning.
`open-source` `local` `free`

### [Doc-to-LoRA](https://pub.sakana.ai/doc-to-lora/) — `02.2026`

Generate a LoRA adapter directly from a document — instant knowledge injection without manual training.
`open-source` `research`

---

## Model Customization Platforms

### [Replicate](https://replicate.com/)

Run and fine-tune open-source models via API; supports custom training runs.
`api` `paid` `platform`

### [fal.ai](https://fal.ai/)

Fast inference and fine-tuning platform for image and video models.
`api` `paid` `platform`

### [Civitai](https://civitai.com/)

Community hub for sharing and downloading LoRA models, checkpoints, and embeddings — primarily for image generation (FLUX, SD).
`online` `free` `platform`
