# Web Scraping & Data Extraction

> AI-powered tools for web scraping and converting web content into structured data. Early-stage category — more entries coming.

### [Firecrawl](https://www.firecrawl.dev/) — `04.2024`

Convert any website into LLM-ready structured data; handles JS-rendered pages, PDFs, and dynamic content.
`open-source` `api` `freemium`

### [Obsidian Web Clipper](https://obsidian.md/clipper) — `04.2026`

Browser extension to save and structure web content directly into Obsidian notes.
`free`
